Ordinary Least Squares linear regression using scikit-learn's [`LinearRegression`](https://scikit-learn.org/stable/modules/generated/sklearn.linear_model.LinearRegression.html).

## Basic Usage

```python
from epftoolbox2.models import OLSModel

model = OLSModel(
    predictors=[
        "load_actual",
        "is_monday_d+{horizon}",
        "is_tuesday_d+{horizon}",
        "is_wednesday_d+{horizon}",
        "is_thursday_d+{horizon}",
        "is_friday_d+{horizon}",
        "is_saturday_d+{horizon}",
        "is_sunday_d+{horizon}",
        "is_holiday_d+{horizon}",
        "daylight_hours_d+{horizon}",
    ],
    training_window=365,
    name="OLS",
)
```

## Parameters

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `predictors` | List or function | Required | Predictor specifications (strings, `{horizon}` templates, or callables), or a [function of `ctx`](/epftoolbox2/model-pipeline/predictor-functions/) returning the list for each forecast |
| `training_window` | int, `"expanding"` or list | `365` | Days of training data (an int from 1), `"expanding"` for every row from the frame's first date, or a list such as `[56, 84, 728, "expanding"]` whose windows are fitted separately and averaged in the model. See [Training Windows](/epftoolbox2/model-pipeline/training-windows/) |
| `name` | str | `"Model"` | Display name for reports |
| `scaler` | str, dict or scaler | `"standard"` | `"standard"`, `"asinh"`, `"mlog"`, `"poly"` or `"npit"`, or `{"name": ..., "params": {...}}`. See [Scalers and VSTs](/epftoolbox2/models/scalers/) |
| `newest_target` | str | `"d-1"` | The newest target a forecast issued on D trains on: `"d-1"`, or `"published"`, every target its rule says is known by the issue time, which needs an information set. See [The newest target](/epftoolbox2/model-pipeline/time-and-calendars/#the-newest-target) |
| `refit` | str or None | `None` | How often the model is fitted: `None` fits every forecast on its own, `"kD"` once every k days and `"kMS"` on the first of every k-th month (k a whole number from 1), on a fixed calendar, such as `"7D"` (Mondays) or `"1MS"`; `"auto"` a window of up to 84 days daily and a longer one weekly. See [Refitting on a calendar](/epftoolbox2/model-pipeline/time-and-calendars/#refitting-on-a-calendar) |
| `binary_mask` | str or None | `None` | Which training rows decide the binary 0/1 columns the scaler leaves unscaled: `None` the window's first day (each unit's rows with `refit`), `"first_day"` the same by name (raises with `refit`), `"fit"` each fit's own rows, so that no forecast depends on `test_start`. See [Binary columns and `test_start`](/epftoolbox2/model-pipeline/time-and-calendars/#binary-columns-and-test_start) |
| `normalise_by`, `bounds`, `zero_when` | str, (low, high), str | `None` | A per-row target: each training row's target divided by its value of the `normalise_by` column and the forecast multiplied by the issue row's, the forecast clipped to `bounds` (in multiples of that scale), and 0 with no fit where the issue row's `zero_when` column is 1. See [Generation targets](/epftoolbox2/models/common-parameters/#generation-targets) |
| `fit_intercept` | bool | `False` | Keyword-only. Fit an intercept on the standardised data. Off by default: the target is standardised and a one-hot set of dummies carries the level. An expert model with a few dummies that aren't a one-hot needs it, see [What the study needs](/epftoolbox2/model-pipeline/week-ahead/#what-the-study-needs) |

Callable predictors accept `(horizon)` or `(horizon, hour)`: the two-parameter form enables features that differ by hour of day:

```python
# horizon-only
lambda horizon: f"price_lag_d-{horizon-7}"

# horizon + hour of day
lambda horizon, hour: f"load_h{hour:02d}_d+{horizon}"
```

## Example

```python
from epftoolbox2.pipelines import ModelPipeline
from epftoolbox2.models import OLSModel
from epftoolbox2.evaluators import MAEEvaluator
from epftoolbox2.exporters import TerminalExporter

predictors = [
    "load_actual",
    "is_monday_d+{horizon}",
    "is_tuesday_d+{horizon}",
    "is_wednesday_d+{horizon}",
    "is_thursday_d+{horizon}",
    "is_friday_d+{horizon}",
    "is_saturday_d+{horizon}",
    "is_sunday_d+{horizon}",
    "is_holiday_d+{horizon}",
    "daylight_hours_d+{horizon}",
    *[f"load_actual_d-{i}" for i in [1, 7]],
]

pipeline = (
    ModelPipeline()
    .add_model(OLSModel(predictors=predictors, name="OLS"))
    .add_evaluator(MAEEvaluator())
    .add_exporter(TerminalExporter())
)

report = pipeline.run(data=df, test_start="2024-02-01", test_end="2024-03-01")
```
