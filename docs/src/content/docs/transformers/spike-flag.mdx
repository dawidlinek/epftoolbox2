# SpikeFlagTransformer

Flags values far from the recent history of the same slot: `{column}_spike` is 1 for a spike and 0 otherwise.

For a row at 19:00 on local day D, the reference band is median ± k·MAD of the column's 19:00 values on the
`window` calendar days before D. Day D itself is not in the band (like pandas' `closed="left"`), so a flag uses
only its own value and earlier days. MAD is multiplied by 1.4826, which makes it estimate the standard deviation
for normally distributed data.

## Basic Usage

```python
from epftoolbox2.data.transformers import SpikeFlagTransformer, LagTransformer

df = SpikeFlagTransformer(columns="price", window=28, k=3.0).transform(df)  # adds price_spike
df = LagTransformer(columns="price_spike", lags=[1], freq="day").transform(df)  # price_spike_d-1
```

## Parameters

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `columns` | str \| List[str] | required | Column name(s) to flag; adds `{column}_spike` for each |
| `window` | int | `28` | Number of previous calendar days in the reference band |
| `k` | float | `3.0` | Band half-width in scaled MADs |
| `min_periods` | int \| None | `None` | Past values needed for a flag; `None` means half the window |
| `side` | str | `"both"` | `"both"`, `"upper"` (only values above the band) or `"lower"` |

## Behaviour

- The flag is NaN when the value is missing or the band has fewer than `min_periods` past values, for example in
  the first days of the data.
- Days count as calendar days, so a gap in the data doesn't stretch the window further back.
- On the autumn DST switch day both 02:00 rows are compared with the same band; the band's history uses the first
  of the two.
- A flag on D is known when a forecast is issued on D only if the value itself is (day-ahead prices are). For
  realised series use it lagged, as `price_spike_d-1` above.

On a UTC index the "days" are UTC days, and the transformer warns.
